# Sistema de Gestión de Contactos

## Descripción del Proyecto
Este proyecto es una aplicación de consola desarrollada en Python para administrar una agenda de contactos. Permite registrar, buscar, editar y eliminar información personal de manera eficiente.

El proyecto fue desarrollado como parte de la evaluación del Módulo 2, aplicando conceptos de **Programación Orientada a Objetos (POO)** y estructuras de datos.

## Estructura del Proyecto
- `main.py`: Contiene el código fuente principal, incluyendo la clase `Contacto` y `GestorContactos`.
- `test_contactos.py`: Contiene las pruebas unitarias realizadas con `unittest`.
- `informe_pruebas.txt`: Resultados de la ejecución de las pruebas.

## Funcionalidades
1. **Agregar Contacto:** Guarda nombre, teléfono, email y dirección.
2. **Buscar Contacto:** Permite búsqueda por nombre o número de teléfono.
3. **Editar Contacto:** Actualiza los datos de un contacto existente.
4. **Eliminar Contacto:** Remueve un contacto de la lista.

## Requisitos Previos
- Python 3.x instalado.
